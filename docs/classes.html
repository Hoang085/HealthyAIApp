Quy ước đọc bảng

Cột Lớp ghi cả loại khai báo (class, data class, object, enum, interface) vì nó quyết định cách dùng: object = hàm thuần/singleton không trạng thái, data class = dữ liệu bất biến, interface = cổng để tầng trên không phụ thuộc Android. Cột Quản lý là dữ liệu/trạng thái lớp đó sở hữu; cột Chức năng là việc nó thực hiện.
