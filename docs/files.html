Hai điều cần biết về môi trường build
  • Repo không commit Gradle wrapper (gradlew/gradlew.bat) ⇒ dùng Gradle đã cài hoặc Gradle tool window của Android Studio. Bắt buộc JDK 21 (jvmToolchain(21)).
  • local.properties đã bị .gitignore nên khoá Gemini không bao giờ vào git. File thiếu cũng không sao: khoá rơi về chuỗi rỗng ⇒ app báo "chưa cấu hình khoá AI" thay vì crash.

6. Tra cứu: muốn hiểu X thì đọc file nào?

Muốn hiểu…Đọc file
App khởi động ra saoHiltApplication.kt → MainActivity.kt → navigation/AppNavigation.kt
Luật phụ thuộc giữa các tầngdi/AppModule.kt (bảng interface → impl) và bất kỳ file nào trong domain/ (xem phần import)
Vì sao domain/ không biết Androiddomain/usecase/steps/StepCounterMath.kt — chỉ có java.time và toán
Cách thêm một thiết lập người dùng mớidata/repository/SettingsRepositoryImpl.kt + data/local/dao/settings/SettingsDao.kt (bảng khoá–giá trị, không cần migration)
Cách nâng version schema DBdata/local/migration/DatabaseMigrations.kt + data/local/AppDatabase.kt + local/migration/DatabaseMigrationsTest
